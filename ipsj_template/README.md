# 和文2段組 投稿用 LaTeX テンプレート（A4・指定マージン準拠）

シンポジウム／研究会系の投稿規定に合わせた A4・2段組テンプレートです。
Overleaf でそのまま利用できます。

## レイアウト条件

| 項目 | 値 |
|------|----|
| 用紙 | A4（210mm × 297mm） |
| 上マージン | 30mm |
| 下マージン | 25mm |
| 左マージン | 20mm |
| 右マージン | 20mm |
| コラム間 | 7mm |
| ノンブル（ページ番号） | なし |

これらは `geometry` パッケージで厳密に指定しています。論文誌の
`ipsj.cls` は独自レイアウトを固定するため上記マージンを満たせず、
本テンプレートでは使用していません（旧 ipsj.cls 版は git 履歴に残っています）。

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `main.tex` | 本文（A4・2段組・ノンブルなし） |
| `references.bib` | 参考文献データベース（BibTeX） |
| `latexmkrc` | uplatex + dvipdfmx でのビルド設定 |
| `ipsjsort.bst` | **要ダウンロード**（参考文献スタイル。学会配布） |

## セットアップ手順（Overleaf）

1. 参考文献スタイル `ipsjsort.bst` を入手し、このフォルダにアップロードする。
   （別スタイルを使う場合は `main.tex` の `\bibliographystyle{}` を変更）
2. Overleaf の `Menu > Settings` で次を設定する。
   - **Compiler**: `LaTeX`
   - **TeX Live version**: 最新
   - **Main document**: `main.tex`
3. コンパイルすると `latexmkrc` により
   `uplatex → upbibtex → uplatex(×2) → dvipdfmx` の順で PDF が生成される。

## 投稿前のチェックリスト

- [ ] **PDF が A4 であること**を必ず確認する（プロパティで 210×297mm）。
      本テンプレートは `geometry` に `dvipdfmx` ドライバを指定して papersize
      special を出力するため A4 になるが、変換経路によってはレターサイズに
      なる場合があるので最終 PDF を必ず目視確認すること。
- [ ] **ページ番号（ノンブル）が入っていない**こと。
- [ ] **なるべく偶数ページ**に収めること。
- [ ] マージン（上30/下25/左右20mm・コラム間7mm）が保たれていること。

## 費用に関する注意（投稿規定より）

- 3ページ目以降は **1ページあたり 4,400円（税込）** の追加ページ代が発生する。
  例: 4ページ投稿 → 2ページ分 → 4,400円 × 2 = 8,800円（講演参加費とは別）。
- このためページ数は **偶数かつ最小限** になるよう調整するのが望ましい。

## 注意

- 日本語組版のため、コンパイラは **uplatex + dvipdfmx** を使う。
  pdfLaTeX / XeLaTeX / LuaLaTeX ではコンパイルできない。
